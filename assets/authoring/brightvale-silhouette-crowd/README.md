# Brightvale waist-up crowd source

`pilot-candidate-waist-up.png` is the current user-approved source (SHA-256 `92cbcf67c40fea19978aaba31cb49ce0600f7bbfe886d7d076c34ce2b2d5c5ed`). It is the sole maintained crowd artwork source in this authoring package. Earlier chest-up experiments and their cleanup/review images were superseded and removed; their history is not a current visual or production authority.

The current atlas derivative, reproducible producer/reviewer, validation report, and retained derivative QA are in [`assets/production/brightvale-silhouette-crowd/`](../../production/brightvale-silhouette-crowd/). Run the producer and pixel-fixture tests documented there to reproduce and check the atlas. The source artwork itself is not edited by that pipeline.

Crowd composition is a runtime responsibility. The retired 3D pose bank and its Blender review/animation pipeline are not inputs to the current crowd or to the shared city/playfield review harness.
