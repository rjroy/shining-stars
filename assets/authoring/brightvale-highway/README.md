## Reproduce and validate

Requires Blender 5.2.1 LTS only. The approved model is self-contained. The generator resolves sibling approved source paths relative to itself; regeneration needs both original `.blend` inputs in the same relative authoring layout. It requires an explicit **new** output directory inside this package or `/tmp/opencode`, refuses existing outputs and never overwrites approved `highway.blend` or the reference sources. It deliberately emits `highway-candidate.blend` with historical candidate labels; regeneration alone does not approve a future revision. `validate.py` defaults its geometry/material comparison to stable `highway.blend`; `--compare` can explicitly select a preserved independent rebuild. `--length` accepts **6…60** provisional units (a guardrail, not a performance/gameplay budget); changing it never changes lane pitch/order, timing or runtime code.

```bash
ASSET="$PWD/assets/authoring/brightvale-highway"
WORK="$(mktemp -d /tmp/opencode/highway-check.XXXXXX)"
timeout 120s blender --background --python-exit-code 1 --python "$ASSET/build.py" \
  -- --output-dir "$WORK/rebuild" --length 18
timeout 180s blender --background "$WORK/rebuild/highway-candidate.blend" \
  --python-exit-code 1 --python "$ASSET/validate.py" \
  -- --negative-test --compare "$ASSET/highway.blend" --report "$WORK/validation.json"
timeout 600s blender --background "$ASSET/highway.blend" \
  --python-exit-code 1 --python "$ASSET/preview.py" -- --output-dir "$WORK/previews"
cwebp -lossless -z 6 "$WORK/previews/neutral-isolated.png" -o "$WORK/neutral-isolated.webp"
```
