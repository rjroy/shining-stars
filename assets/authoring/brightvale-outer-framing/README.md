Relocate the package **with those sibling inputs**; there is no session-specific scratch dependency. Outputs require an explicit NEW directory under this package or `/tmp/opencode`; missing, existing and outside-scope outputs are refused before loading source. It intentionally still writes a new `framing-candidate.blend` in that new directory, never silently overwriting approved `framing.blend`. A future rebuild is not automatically approved. The stored study pose and its validation are preview isolation/reproduction evidence, not a final arrangement contract.

ASSET="$PWD/assets/authoring/brightvale-outer-framing"

timeout 120s blender --background --python-exit-code 1 --python "$ASSET/build.py" -- --output-dir "$OUT"
