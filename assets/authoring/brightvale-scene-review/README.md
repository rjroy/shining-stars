# Brightvale shared city/playfield study

This package retains the editable scene composition and source authoring assets for city, platform, highway, endcaps, framing and ground review. The old static 3D crowd layer is retired. `scene-review.blend`, its old validation report and captures are retained as historical artifacts and still depict that former crowd; they are not current crowd authority.

`build.py --output <new .blend>` reproduces the shared study in owned scratch: source assembly, generated 42-unit highway, playfield composition, semicircular framing, and two-level ground. The retired crowd placement stage is omitted. Non-crowd checks cover city/ground contact, plaza geometry, framing joints, and unobstructed highway lanes. The current waist-up crowd source and atlas pipeline are documented in [`../brightvale-silhouette-crowd/README.md`](../brightvale-silhouette-crowd/README.md).

Source packages remain separately owned: [platform](../neon-twilight-platform/), [endcaps](../brightvale-platform-endcaps/), [highway](../brightvale-highway/), [framing](../brightvale-outer-framing/) and [city](../brightvale-distant-city/). This study establishes no new source approval, game integration, final appearance acceptance, or device performance budget.
